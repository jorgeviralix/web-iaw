# web-iaw

Práctica de Git y GitHub para la asignatura de Implantación de Aplicaciones Web (IAW), 2.º ASIR, SAFA Andújar.

## Descripción
Proyecto web sencillo construido con HTML y CSS que sirve para practicar el flujo completo de Git: crear repositorio local, hacer commits, publicar en GitHub, trabajar con ramas y resolver conflictos.

## Requisitos
- Git instalado
- Un editor de código (Visual Studio Code)
- Cuenta de GitHub

## Instalación
Clonar el repositorio con `git clone git@github.com:jorgeviralix/web-iaw.git`

## Ejecución
Abrir `index.html` en el navegador.
